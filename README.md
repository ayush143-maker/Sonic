# Sonic

A browser-based music visualiser with multiple visual modes, colour options, track upload, playback controls, and a song list. The main entry point is `Sonicv2.html`; no package installation is required.

## Open locally

Open `Sonicv2.html` in a modern browser, or start a local HTTP server:

    python -m http.server 8000

Visit the local address shown by the server and open `/Sonicv2.html`.

## Using local audio

Choose an audio file through the page's upload control. Browser audio policies may require a direct user action before sound starts.
